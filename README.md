# Search Launcher

A ultra-minimalist, search-first Android launcher. By default, the launcher displays nothing but a pure black screen and an elongated bottom search bar. Apps appear directly above the search bar as you search for them, putting the exact app you want right at your thumb.

For my personal-usage only, that's why I'm trying to make it as simple as possible. If you want to add your own additional features, you can fork it.
