# Search Launcher

A very simple & lightweight launcher for Android. Search the app that you want to open using the bottom search bar. Free, open-source, and no nonsenses. Requires Android 8 (API Level 26).

For my personal-usage only, that's why I'm trying to make it as simple as possible. If you want to add your own additional features, you can fork it.

---

## Features

- Search bar that's positioned on the bottom of your screen, easier to reach with one-hand.
- Very simple by default. App would only appear when you search it.
- Pure black wallpaper background that helps you stay focused.
