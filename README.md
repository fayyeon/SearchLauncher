# Search Launcher

A ultra-minimalist, search-first Android launcher. By default, the launcher displays nothing but a pure black screen and an elongated bottom search bar. Apps appear directly above the search bar as you search for them, putting the exact app you want right at your thumb.

For my personal-usage only, that's why I'm trying to make it as simple as possible. If you want to add your own additional features, you can fork it.

## Features
- **Distraction-Free AMOLED Black**: Clean, battery-saving pure black canvas with zero clutter.
- **Search-First Interaction**: Apps only appear as you search for them; pressing Enter immediately launches the top match.
- **Double Tap to Lock**: Double tap anywhere on the screen to turn off and lock the display (uses Android Accessibility Service API, keeping fingerprint and face unlock intact).
- **Ultra Lightweight**: Full ProGuard/R8 dead-code stripping and resource shrinking (~900 KB APK).
